## 0. 范围与基线

- **设计稿共 15 个页面框**，本轮**剔除 2 个**（银行卡备份 `2:133`/`2:912`、周期记账 `2:134`/`2:940`，已在前序 sprint 完成），故**本轮复刻 13 个页面**，每个均含**浅色 + 深色素材**（共 26 个设计节点）。
- **液态玻璃第三套主题本轮不实现为可用主题**（后续独立主题工程）；但 AppearanceSheet 与 SettingsPage 的「界面风格 / 外观」均**显示双选项 `[默认(可选) | 液态玻璃(置灰禁用 + 「即将推出」)]`，玻璃不可点**（见 A5）。
- **环境约束**：本机无 Flutter SDK，全程静态实现 + 设计稿数值对照；编译门由 CI 把关。
- **复用优先**：所有页面已有对应 `.dart` 文件，基础设施（色板/共享组件/全局控件）齐备，**不另起炉灶**。
- **唯一事实源**：颜色全部走 `AppColors` 的 `light*`/`dark*` 设计令牌；所有像素数值以对应 Ardot 节点 id 为准。**禁止硬编码颜色/尺寸**。

## 1. 产品目标 & 成功标准

### 1.1 产品目标
把网页端参考 UI 在 Flutter 中**逐像素 1:1 复刻**，使 13 个页面在浅色与深皮下均与设计稿视觉一致，并复用既有 `AppColors` 令牌体系与共享组件，保证可维护性与主题一致性。

## 3. 共享设计语言规范（架构师/工程师统一基准）

### 3.1 三段式布局（全部页面）
```
┌─────────────────────────┐
│ 顶部全局控件区 (y≈14)     │  ← HomeButton(左,top-3 left-3) + FloatingToolbar(右,top-3 right-3)
├─────────────────────────┤
│ 中部内容区 (SingleChildScrollView) │  ← 容器 padding 见 §3.2
├─────────────────────────┤
│ 底部 PwaInstallPrompt (fixed bottom-4) │  ← 全局固定，内容区底部预留 24px
└─────────────────────────┘
```

### 3.2 容器约定
- **首页 / 登录**：不使用标准子页头部。顶部自绘（状态栏时间 `y:22`，顶部控件 `y:14`）。
- **其余 11 个子页**：内容容器统一 `padding: EdgeInsets.fromLTRB(24, 56, 24, 24)`（= px-6 pt-14，顶部 56px 清开左上/右上控件）。
- **「返回」放左侧**：`‹ 返回` + 标题 `flex-1`，**勿放右侧**（会撞右上 FloatingToolbar）。

## 6. UI 设计参考说明

### 6.1 三段式布局（本机适配要点）
1. **顶部全局控件区**：状态栏时间 `y:22`（首页/登录）；`HomeButton`(左) 与 `FloatingToolbar`(右) 固定 `top-3`，不随内容滚动。子页由统一头部组件渲染（见 A3）。
2. **中部内容区**：`SingleChildScrollView` + 容器 padding（首页/登录自绘顶部，其余 `(24,56,24,24)`）。卡片宽固定 342、圆角 16、1px 描边、无重阴影（扁平风，见 `app_theme.dart` `elevation:0`）。
3. **底部安装提示**：`PwaInstallPrompt` `fixed bottom-4` 全局沿用（登录页 N/A，见 A8），内容区底部预留 24px 避免遮挡。

### 6.2 适配与一致性
- 画布基准 390pt；所有横向尺寸按 gutter 24 推导，避免写死绝对像素（除设计明确值外）。
